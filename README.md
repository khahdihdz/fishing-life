# FISHING LIFE – Hành Trình Câu Cá

Game câu cá 2D Pixel Art bằng Python + Pygame, ưu tiên Android cảm ứng.

## Android (Pydroid 3)
1. Cài Pydroid 3.
2. Cài pygame trong Pip.
3. Mở `main.py` và nhấn Run.

## PC / môi trường có màn hình
```bash
pip install -r requirements.txt
python main.py
```

## Điều khiển
Chạm THẢ CẦN, chờ cá cắn, chạm GIẬT CẦN, rồi giữ KÉO CÁ để tăng tiến độ. Các nút Cửa hàng, Địa điểm, Bộ sưu tập và Nhiệm vụ ở cuối màn hình. ESC để quay lại/thoát.

## Nội dung
50 loài cá, 8 địa điểm, 4 bậc hiếm, nâng cấp dụng cụ, bán cá, nhiệm vụ, cấp độ và lưu JSON tự động tại `saves/progress.json`.

Đồ họa pixel được vẽ bằng Pygame primitives, không cần tải asset ngoài.
